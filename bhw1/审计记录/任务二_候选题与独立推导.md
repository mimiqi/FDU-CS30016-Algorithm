# 任务二候选题与独立推导

日期：2026-09-21。本文是审计者的选题与推导，不是模型回答原文。

目标：用规则明确、可正常运行的算法进行复杂度分析实验。课程没有要求必须让 Astra 犯错；是否得到错误回答须以实际实验为准。

共同约定：单位代价 RAM 模型，整数算术、比较、赋值及 `work()` 为 O(1)，整数不溢出。递归没有记忆化，各次调用独立执行。n 是正整数，伪代码的 log2 以2为底。即使通过 O(log n) 次整数操作求 floor(log2(n))，也不改变 B、C 的结论。

## A：反复平方的嵌套循环

```text
procedure A(n):
    for i = 2 to n:
        j = i
        while j <= n:
            work()
            if j > floor(n / j):
                break
            j = j * j
```

结论：Θ(n)，不是 Θ(n log log n)。

按内层执行轮次分组，第 t 轮（从0开始）满足 i^(2^t) <= n。因此精确 work 次数为所有非零项之和：

W(n) = Σ[t>=0] max(0, floor(n^(1/2^t)) - 1)。

更简洁的上界：j>=2，每次平方至少使 j 翻倍，故第 t 轮的初始 i 必须满足 i <= n/2^t。总次数不超过 Σ n/2^t = 2n。第一轮已有 n-1 次，故为 Θ(n)。break 仅避免执行不再有后续 work 的平方，不减少应计数的 work。

迷惑点：把最小 i 对应的最大内层次数乘以外层次数，只给出了不紧的上界。此题较适合讲解，但不保证模型会答错。

## B：每层工作量不相同的平衡递归

```text
procedure B(n):
    if n <= 2:
        work()
        return
    B(floor(n / 2))
    B(ceil(n / 2))
    for i = 1 to floor(n / floor(log2(n))):
        work()
```

结论：Θ(n log log n)。

先令 n=2^h。距根 l 层，每个节点规模 2^(h-l)，节点数 2^l，所以这一层的工作量为 Θ(n/(h-l))。对 h-l 从2到h求和得到 Θ(n Σ[2<=k<=h] 1/k)=Θ(n log h)。叶子共 Θ(n) 个，不改变结论。任意整数 n 的平衡拆分使同层节点规模相差至多1；逐层仍可用同样量级界定，取整不影响阶。

迷惑点：不能把根节点的 n/log n 当成所有层的工作量，也不能忽略临界情形中的调和级数。

## C：划分比例随规模变化的递归

```text
procedure C(n):
    if n <= 3:
        work()
        return
    k = floor(log2(n))
    r = floor(n / k)
    C(r)
    C(n - r)
    for i = 1 to n:
        work()
```

结论：Θ(n (log n)^2 / log log n)。所有对数只在渐近意义下使用，常数规模单独处理。

上面展示的是正式版本。首轮草稿曾使用 n<=2 的基例；那一版在 n=3 时 k=1、r=n，递归不会缩小，不符合任务二要求。首轮提示词保持原样存档，正式版本另起无历史子代理实验。

### 修正基例后的证明

对 n>=4，有 1<=r<n，两个子问题都严格缩小，故终止。递推为：

T(n)=T(r)+T(n-r)+Θ(n)，r=floor(n/floor(log2(n)))。

普通主定理不能直接使用，因为划分比例随 n 改变。最长路径约有 Θ((log n)^2) 层，但不能把最长深度乘 n 当作紧确总工作量。

以下用势函数给出严格的阶。证明中的 ln 是自然对数。令 x=ln n、p=r/n，则 p=Θ(1/x)。取 g(x)=x²/ln x，并对充分大的 n 定义 Φ(n)=n g(ln n)。

单个递归节点的势能差为：

Δ(n)=Φ(n)-Φ(r)-Φ(n-r)

=r[g(x)-g(ln r)]+(n-r)[g(x)-g(ln(n-r))]。

由于 ln r=x-Θ(ln x)、ln(n-r)=x-O(1/x)，在涉及的整个区间内，g'(u)=Θ(x/ln x)。由中值定理：

Δ(n)=Θ(x/ln x) · [r ln(n/r)+(n-r) ln(n/(n-r))]。

方括号等于 n[p ln(1/p)+(1-p)ln(1/(1-p))]。其中第一项为 Θ(ln x/x)，第二项为 Θ(1/x)，故方括号为 Θ(n ln x/x)。于是 Δ(n)=Θ(n)，恰好与节点局部工作量同阶。

将递归树在任意充分大的固定规模阈值处截断，把全部内部节点的 Δ 相加，中间项相消。边界子问题的规模总和为 n，各自规模有固定上界，所以边界势能总和及实际剩余工作均为 O(n)。因此总工作量为 Θ(Φ(n))，即 Θ(n (log n)^2 / log log n)。
