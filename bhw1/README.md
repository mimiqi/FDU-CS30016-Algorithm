## 复核与演示

安装有Node.js的环境，在仓库根目录运行：

```powershell
node .\bhw1\验证\rts-audit.cjs
node .\bhw1\验证\rts-independent-answer-audit.cjs
```

需要更新逐 tick 结果时，在对应命令后加 `--write`。主实验结果写入[验证结果](./验证/RTS集火算法_验证结果.json)，补充实验结果写入[新回答验证结果](./验证/RTS集火算法_新回答验证结果.json)。程序失败或达到搜索预算会报错，不会把截断结果当成最优值。

直接用浏览器打开HTML，选择“同属性反例”，切换“旧模型算法”和“人工修正版”，观察 tick 3 与 tick 8—9。网页使用本地脚本，不需要联网。
