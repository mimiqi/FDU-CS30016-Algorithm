## 结论

- B：模型给出 Θ(n log log n)，正确。
- C：模型给出 Θ(n log n / log log n)，错误。正确结论是 Θ(n (log n)^2 / log log n)，模型少算一个 log n 因子。

C 的正式基例为 n<=3；对所有 n>=4，两支都严格缩小，程序终止。本轮错误与此前废弃草稿 n=3 不终止的问题无关。

## 错误发生的位置

模型令 F(n)=n log n/log log n，然后断言：

F(n)-F(r)-F(n-r)=Θ(F(n)·H(p))，p=r/n，H(p)=p log(1/p)+(1-p)log(1/(1-p))。

这一步不成立。自然对数下令 x=ln n、g(x)=x/ln x。实际差为：

r[g(x)-g(ln r)]+(n-r)[g(x)-g(ln(n-r))]。

在涉及区间内，g'(u)=Θ(1/ln x)。由中值定理，差是 Θ(n g'(x)H(p))，不是 Θ(n g(x)H(p))。由于 H(p)=Θ(ln x/x)，实际势能差为 Θ(n/x)=Θ(n/ln n)，不足以抵偿每个节点的 Θ(n) 工作量。模型把函数值和函数的变化率混淆，多估了一个 ln n 因子，进而低估了递归总成本。

## 不依赖精确解的快速反驳

递归树是满二叉树，各叶子的规模在1到3之间，叶子规模总和为 n，所以叶子数 L>=n/3。任意有 L 个叶子的二叉树，叶子深度之和为 Ω(L log L)：深度小于 log2(L/2) 的叶子数量至多 L/2，因此至少一半叶子的深度为 Ω(log L)。

每个内部节点执行与节点规模相等的 work 次数。将节点规模分摊到后代叶子上，总内部 work 次数等于 Σ叶子(叶子规模×叶子深度)，至少为叶子深度之和。因此总时间至少为 Ω(n log n)。

模型给出的 n log n/log log n 是 o(n log n)，连这一普适下界都不满足，故其 Θ 结论确实错误，并非只是证明不够详细。

## 正确结论及复核

取 Φ(n)=n(ln n)^2/ln ln n，对应 g(x)=x²/ln x，导数 g'(x)=Θ(x/ln x)。上述势能差成为 Θ(n)，与节点工作量一致。沿递归树相消求和，常数规模边界总成本为 O(n)，得到正确紧确界 Θ(n(log n)^2/log log n)。完整证明见 `../../审计记录/任务二_候选题与独立推导.md`。
