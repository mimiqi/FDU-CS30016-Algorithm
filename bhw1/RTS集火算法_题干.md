# RTS 单位目标选择优化问题（题干）

## 1. 问题背景

考虑一个类似《星际争霸 II》的即时战略游戏战斗场景。

战场上存在两支相互敌对的部队，记为：

- 己方部队；
- 敌方部队。

双方单位均接收到同一个“A 地板”目标点 $G$，并不断向该位置移动。一旦射程内存在存活敌方单位，该单位必须停止移动；若同时处于 Ready 状态，则可以按照后文规则发动攻击。

在传统 RTS 自动攻击逻辑中，多个单位通常会独立选择攻击目标，因此容易产生“过度集火”现象。

例如，若两个己方单位的单次攻击均可造成 40 点实际伤害，而某个敌方单位当前只剩 45 点生命值，那么两个单位同时攻击该目标时，共造成 80 点伤害，但其中 35 点伤害实际上没有产生额外收益。

本问题希望研究：

> 在敌方行为完全确定的情况下，通过控制己方单位每次攻击时的目标选择，使己方在战斗结束时保留尽可能多的总生命值。

---

# 2. 战场空间

战场使用二维笛卡尔坐标系。

任意单位 $i$ 在某一时刻的位置表示为：

```math
(x_i,y_i)
```

两个单位 $i,j$ 之间的距离定义为标准欧氏距离：

```math
\operatorname{dist}(i,j)=\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}
```

所有单位均视为几何意义上的点。

不考虑：

- 单位模型半径；
- 单位碰撞；
- 路径阻挡；
- 地形阻挡；
- 寻路；
- 单位之间互相卡位。

多个单位允许处于完全相同的坐标。

---

# 3. 单位属性

每个单位 $i$ 具有以下属性：

```math
(x_i,y_i,H_i,A_i,D_i,c_i,R_i,v_i)
```

其中：

- $(x_i,y_i)$：当前二维坐标；
- $H_i$：当前生命值；
- $A_i$：护甲值；
- $D_i$：攻击力；
- $c_i$：攻击间隔，单位为 tick；
- $R_i$：攻击射程；
- $v_i$：每个 tick 可以移动的最大距离。

上述数值允许为小数，但攻击间隔 $c_i$ 使用整数 tick 表示。

单位编号唯一。

己方单位和敌方单位可以拥有完全不同的属性。

---

# 4. 时间系统

游戏时间被离散为连续的 tick：

```math
t=0,1,2,3,\dots
```

一个 tick 是游戏中的最小时间分度。

所有：

- 攻击选择；
- 攻击结算；
- 死亡判定；
- 移动；

均基于 tick 进行。

---

# 5. 初始攻击状态

所有单位在战斗开始时均处于攻击可用状态。

因此，在：

```math
t=0
```

时，只要满足其他攻击条件，单位即可立即发动第一次攻击。

不存在：

- 攻击前摇；
- 抬手时间；
- 弹道飞行时间；
- 攻击后摇。

攻击一旦发生，其伤害在当前 tick 立即参与结算。

---

# 6. 攻击间隔与冷却

单位 $i$ 的攻击间隔为：

```math
c_i
```

如果单位 $i$ 在第 $t$ 个 tick 发动攻击，那么它下一次最早可以在：

```math
t+c_i
```

再次发动攻击。

例如：

```math
c_i=10
```

且单位在：

```math
t=0
```

发动攻击，则它：

- 在 tick 1 到 tick 9 之间不能再次攻击；
- 在 tick 10 时重新进入攻击可用状态。

攻击冷却期间，单位仅在射程内不存在存活敌方单位时正常移动；只要射程内存在敌方单位，即使仍在冷却也必须停在原地。

---

# 7. Ready 状态

如果一个单位已经完成攻击冷却，则称该单位处于：

```math
\text{Ready}
```

状态。

如果一个单位已经 Ready，但是当前没有发动攻击，则：

> Ready 状态会一直保留。

攻击机会不会因为没有立即使用而消失。

例如，一个单位在 tick 10 已经完成冷却，但直到 tick 15 才选择攻击：在此期间，只有当其射程内不存在存活敌方单位时，它才会继续移动；若射程内已有敌人，则保持 Ready 并停在原地。

该次攻击发生后，再重新开始新的 $c_i$ tick 冷却。

---

# 8. 攻击范围

单位 $i$ 可以攻击单位 $j$，当且仅当：

```math
\operatorname{dist}(i,j)\le R_i
```

其中 $R_i$ 为攻击者 $i$ 的攻击射程。

射程只由攻击者自身属性决定。

不考虑目标单位的模型大小。

---

# 9. 单次攻击伤害

单位 $i$ 攻击单位 $j$ 时造成的实际伤害为：

```math
\max(0.5,D_i-A_j)
```

其中：

- $D_i$ 是攻击者攻击力；
- $A_j$ 是目标护甲值。

因此任何一次合法攻击都至少造成：

```math
0.5
```

点伤害。

攻击不存在：

- 暴击；
- 闪避；
- 命中率；
- 随机伤害；
- 属性克制；
- 攻击类型；
- 护盾；
- 回复；
- 吸血；
- 范围伤害。

所有攻击均为确定性的单体伤害。

---

# 10. 无弹道伤害

所有攻击均视为：

> 点对点、无弹道、瞬时结算攻击。

攻击一旦在某个 tick 被确定发动，其伤害就会在该 tick 的伤害结算阶段生效。

不存在：

- 弹道飞行时间；
- 子弹被躲避；
- 目标在弹道抵达前死亡；
- 移动导致弹道落空。

---

# 11. 同时攻击

如果多个单位在同一个 tick 发动攻击，则这些攻击视为同时发生。

所有攻击目标的确定，都基于：

> 当前 tick 伤害结算开始前的游戏状态。

随后，该 tick 的所有攻击同时进行伤害结算。

例如：

单位 A 和单位 B 均有 40 点实际伤害。

某敌方单位当前生命值为：

```math
45
```

如果 A 和 B 在同一 tick 都选择该单位作为目标，那么两次攻击都会正常生效。

该单位共受到：

```math
80
```

点伤害。

即使第一发攻击从数值上已经足以改变第二发攻击的价值，第二发攻击仍不会被取消或重新选择目标。

---

# 12. 同归于尽

由于同一 tick 的攻击同时结算，因此两个单位可以互相击杀。

例如：

- A 在当前 tick 攻击 B；
- B 在当前 tick 攻击 A；
- 两次攻击均足以将对方生命值降至 0 或以下。

那么两次攻击仍然都会生效。

最终结果为：

> A 和 B 同时死亡。

这属于正常且合法的战斗结果。

---

# 13. 单位死亡

当单位生命值满足：

```math
H_i\le 0
```

时，该单位死亡。

死亡单位会立即从战场中移除。

死亡后，该单位：

- 不能移动；
- 不能继续攻击；
- 不能成为之后 tick 的攻击目标；
- 不再参与任何后续战斗计算。

同一 tick 中的死亡不会取消该单位在该 tick 已经确定发动的攻击。

---

# 14. A 地板目标点

双方所有单位共享同一个固定目标点：

```math
G=(G_x,G_y)
```

己方与敌方的 A 地板目标坐标完全相同。

如果一个单位在某个 tick 没有发动攻击、射程内不存在存活敌方单位，并且尚未到达 $G$，则它沿：

> 当前坐标指向 $G$ 的直线方向

进行移动。

---

# 15. 单位移动

单位只有在射程内不存在存活敌方单位时才允许移动。若射程内存在至少一个存活敌方单位，则无论该单位是否 Ready、是否仍在攻击冷却中，以及本 tick 是否选择攻击，都必须保持原位。

单位 $i$ 每个 tick 最多移动：

```math
v_i
```

距离。

假设该单位当前位置到 $G$ 的距离为：

```math
d
```

则本 tick 实际移动距离为：

```math
\min(v_i,d)
```

因此单位不会越过目标点 $G$。

移动完成后：

- 如果尚未到达 $G$，则停在新的位置；
- 如果到达 $G$，则位置固定为 $G$。

---

# 16. 到达目标点后的行为

单位到达 $G$ 后：

> 停留在 $G$，不再继续移动。

但该单位仍然正常参与战斗。

它仍然可以：

- 完成攻击冷却；
- 进入 Ready 状态；
- 选择攻击目标；
- 发动攻击；
- 被敌方攻击；
- 死亡。

如果多个单位同时到达 $G$，它们可以处于完全相同的位置。

---

# 17. 攻击与移动的关系

一个单位在同一个 tick 中：

> 不能同时攻击和移动。

如果某单位在当前 tick 发动攻击，则该单位当前 tick 不发生移动。

如果该单位当前 tick 没有发动攻击，还需要检查其射程内是否存在存活敌方单位：

- 若存在，则保持原位；
- 若不存在，则正常向 $G$ 移动。

因此，例如一个攻击间隔为 10 tick 的单位：

- tick 0 发动攻击；
- tick 1–9 仍在冷却；仅在射程内没有存活敌人时可以移动；
- tick 10 再次进入 Ready 状态。

在 tick 10 时，它既可以：

- 选择攻击并停在原地；

也可以选择：

- 放弃本 tick 攻击并保持 Ready。由于射程内已有合法目标，该单位仍停在原地，不能借此继续向 $G$ 移动。

---

# 18. 己方单位的控制权限

算法只控制：

> 己方单位的攻击决策。

当某个己方单位处于 Ready 状态时，如果其攻击范围内存在一个或多个存活敌方单位，我们可以决定：

1. 攻击其中任意一个合法敌方单位；

或者：

2. 本 tick 不发动攻击。

如果选择不攻击但射程内存在存活敌方单位，则该单位仍须保持原位。

如果己方单位尚未 Ready，则无法攻击；它仅在射程内不存在存活敌方单位时移动。

算法不能修改：

- 单位属性；
- 单位移动速度；
- 单位移动方向；
- 攻击伤害；
- 攻击冷却；
- 敌方行为。

---

# 19. 己方目标选择

己方单位的目标选择不存在固定仇恨规则。

只要敌方单位满足：

```math
\operatorname{dist}(i,j)\le R_i
```

并且仍然存活，则它就是己方单位 $i$ 的合法攻击目标。

己方算法可以在每一次攻击机会出现时重新进行选择。

不存在永久锁定目标。

## 19.1 默认对照算法

为了比较目标选择优化带来的效果，可使用“就近攻击”作为默认对照算法。对每个处于 Ready 状态的己方单位，独立执行以下规则：

1. 找出射程内所有存活敌方单位；
2. 选择距离最近的敌方单位；
3. 若距离相同，则选择编号最小的单位；
4. 若射程内没有合法目标，则保持 Ready，并在移动阶段继续向 $G$ 移动。

各己方单位独立选择，不读取其他己方单位的攻击目标，也不预先计算同一 tick 的合计伤害。该默认算法只用于对照，不属于需要优化的最终答案。

---

# 20. 敌方行为

敌方单位完全由固定的 A 地板逻辑控制。

算法不能控制敌方。

当敌方单位处于 Ready 状态时：

如果攻击范围内存在至少一个存活己方单位，则敌方必须立即发动攻击。

敌方会优先选择：

> 与自己距离最近的己方单位。

即敌方单位 $e$ 会选择使：

```math
\operatorname{dist}(e,i)
```

最小的合法目标 $i$。

如果存在多个距离完全相同的合法目标，则选择：

> 单位编号最小的己方单位。

因此敌方行为是完全确定的，不包含随机性。

---

# 21. 敌方没有攻击目标时

如果敌方单位：

- 已经 Ready；
- 但当前射程内没有任何存活己方单位；

则本 tick 不发动攻击，并继续保持 Ready。

同时，该单位正常向共同目标点 $G$ 移动。

未来任意一个 tick，只要有己方单位进入其攻击范围，该敌方单位即可立即攻击。

---

# 22. 己方没有攻击目标时

如果己方单位已经 Ready，但当前射程内不存在任何存活敌方单位，则无法发动攻击。

该单位继续保持 Ready，并正常向 $G$ 移动。

---

# 23. 单个 tick 的状态变化

对于每一个 tick $t$，游戏状态按照统一规则推进。

在 tick 开始时，确定：

- 所有存活单位的位置；
- 所有存活单位当前生命值；
- 所有单位攻击是否 Ready。

随后进行攻击决策。

己方 Ready 单位由算法决定：

- 是否攻击；
- 若攻击，则选择哪个合法目标。

敌方 Ready 单位按照固定规则决定目标。

所有已经确定的攻击基于当前 tick 结算前的状态同时发生。

完成伤害结算后：

- 所有生命值降至 0 或以下的单位死亡并移除。

如果战斗尚未结束，则对当前 tick 没有发动攻击且仍然存活的单位检查攻击范围。只有射程内不存在存活敌方单位的单位才向 $G$ 移动；射程内存在敌方单位的单位保持原位。

---

# 24. 战斗结束条件

由于双方所有单位都向同一个目标点 $G$ 移动，因此本问题直接假设：

> 战斗一定会持续到至少一方全部单位死亡。

当某个 tick 完成同时伤害结算后，如果出现以下任意情况：

- 敌方全部单位死亡；
- 己方全部单位死亡；

则战斗立即结束。

不再执行该 tick 后续移动。

---

# 25. 双方同时全灭

允许某个 tick 出现：

> 己方最后一个单位和敌方最后一个单位同时死亡。

此时双方同时全灭，战斗同样立即结束。

己方不存在任何存活单位，因此最终己方存活总生命值为：

```math
0
```

---

# 26. 优化目标

设战斗结束时己方存活单位集合为：

```math
S
```

对于每个存活己方单位 $i$，其最终剩余生命值为：

```math
H_i^{\text{final}}
```

定义己方最终存活总生命值为：

```math
V=\sum_{i\in S}H_i^{\text{final}}
```

如果己方全部死亡，则：

```math
V=0
```

算法的目标是：

```math
\boxed{\max V}
```

即：

> 通过合理决定己方单位每一次攻击机会的攻击目标，以及是否暂缓当前攻击，使战斗结束时己方所有存活单位的剩余生命值总和最大。

- 控制效果；
- 治疗；
- 护盾；
- 生命恢复；

- 攻击前摇；
- 攻击后摇；
