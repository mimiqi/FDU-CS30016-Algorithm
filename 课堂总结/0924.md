从分治思想到分布式计算框架
分治算法不仅在单机算法设计中占据重要地位，其“分而治之，合并结果”的思想也被推广到了现代分布式计算系统中。
* 概念映射：
* 子问题 -> 数据分区
* 递归调用 -> 任务图
* 合并结果 -> Shuffle 与聚合
* 经典案例 - MapReduce：以 WordCount 为例，其流程完美体现了分治思想。首先将输入文件拆分为多个分片(Map 阶段)，每个分片独立统计局部词频；然后通过网络将相同单词的计数重排发送到同一个 Reducer(Shuffle 阶段)；最后由 Reducer 汇总得到全局词频(Reduce 阶段)。
* 核心区别：分布式系统不仅关注逻辑上的分治，还必须显式处理数据放置、任务调度、网络通信和故障恢复等工程问题。

分治思想在 AI 领域的应用
这种思想在人工智能领域同样无处不在，例如：
* 决策树：按特征递归地划分子集，是典型的分治。
* k-d 树 / ANN：通过递归分割空间来加速最近邻搜索。
* 大规模矩阵乘法 / 分布式训练：将矩阵分块或将数据拆分到多 GPU 上计算，最后进行聚合。
* Mixture-of-Experts：将输入 Token 分发给不同专家网络，再汇总输出。

分治与并行在大模型推理加速中的应用：Block Diffusion
传统的大语言模型采用逐 Token 接龙式生成，这种方式是串行的，无法充分利用并行能力。尽管训练时可以对已知的前缀进行并行计算，但生成时仍然受限。

Diffusion 思想：受图像生成领域扩散模型和 BERT 掩码语言模型的启发，研究者尝试用“多轮填空”替代“逐词接龙”来生成文本。其核心是文本扩散。
* 训练过程：对真实文本进行随机掩码（Mask），让模型学习从被噪声破坏的文本中恢复出原始内容。
* 生成过程：保留用户提示作为前缀，将回答部分全部用 [MASK] 占位。模型在每一轮迭代中同时预测所有空位，保留置信度高的预测结果，将置信度低的位置重新掩码，进入下一轮迭代，直至所有位置都生成完毕。

局限性与改进：
* 纯扩散方法有两大局限：(1) 固定输出长度：生成前必须预设总 Token 数，不够灵活。(2) 难以复用 KV Cache：每轮迭代整段文本都会变化，导致无法像自回归模型那样缓存和复用注意力机制的中间结果。
* Block Diffusion：为了克服上述局限，提出了分块扩散模型。它将输出序列划分为多个块（Block）。
* 块间顺序：按块自回归生成，前一个块完成后，其结果固定下来，作为生成下一个块的稳定前缀。这使得已完成块的 KV Cache 可以被有效复用。
* 块内并行：在生成新块时，内部采用多轮并行去噪的方式，灵活安排该块内所有 Token 的生成顺序，复用了扩散模型的并行优势。
* 这种设计巧妙地将自回归模型和扩散模型的优点结合起来，实现了支持灵活长度、KV缓存可复用、生成质量高的并行文本生成。

随机算法
从本讲开始，课程内容转向随机算法。设计随机算法的目的不是让算法的输入随机，而是在算法的逻辑执行过程中引入随机数，以帮助解决问题。

引入随机性的动机
打破对称性：在分布式系统等场景中，当多个确定性进程处于相同状态并执行相同规则时，可能会陷入永久的冲突或死锁。引入随机退避等策略，可以让它们自然地走向不同的选择，打破僵局。
避免最坏输入：确定性算法总是存在一个使其性能降至最坏情况的输入。随机化使得算法行为不可预测，对手无法针对性地构造出总是导致最坏情况的输入。
避免为寻找最优解付出过大代价：例如在快速排序中，随机选择枢纽元（pivot）可以大概率获得较好的划分，而无需花费高昂代价去精确寻找中位数。
用极小错误概率换取巨大效率提升：一些验证问题，如矩阵乘法验证和素数判定，通过随机化算法可以用小得多的时间复杂度完成，仅以极低的错误概率为代价。
简化算法设计：例如 Miller-Rabin 素数测试，其设计和分析比绝对的确定性算法简单得多。
总言之，随机性让单次行为变得不可预测，但整体性能可以通过概率得到严格的控制和保证。

随机化思想的延展与应用
分布式系统中的随机化
共识算法 Ben-Or 协议：
背景：FLP 不可能性定理指出，在完全异步且存在进程崩溃的系统中，任何确定性的共识协议都可能永远无法达成一致。
思想：该协议巧妙地引入随机性来绕过此不可能性。协议在每一轮中，进程首先尝试靠“多数投票”来决定值（如 0 或 1）；如果无法形成多数，每个进程就随机选择一个 0 或 1，然后进入下一轮。
核心：虽然每一轮的选择是随机的，但每一轮都有非零的概率（）将系统推向一个可收敛的状态，使得所有进程最终找到多数。经过足够多的轮数，协议最终达成共识的概率趋近于 1。
负载均衡：Power of Two Choices：
问题：将  个任务（球）随机投入  个服务器（桶）。若每个球都完全随机选择一个桶，最满的桶的负载为 。
改进：采用“两次选择”策略。每个球到达时，随机选择两个桶，并总是放入当前负载较轻的那个桶中。
效果：此简单改动使最大负载指数级地降至 。其原理在于，一个已经很满的桶要变得更满，必须是两次随机选择都选到了它或同样满的桶，其概率会近似平方级地递减。
随机化在数据隐私中的应用：差分隐私
动机：在数据库查询中，即使只返回聚合统计值（如患病总人数），也可能泄露个人隐私。攻击者若观察到 Alice 加入数据库前后查询结果从 237 变成 236，就能推断出 Alice 患有该疾病。
