动态规划在大模型推理优化中的应用
算法课的基本思想方法在当代大模型系统中仍然有直接应用。本讲特意介绍的 Sequoia 论文将动态规划用于推测解码的优化。推测解码的基本思路是用小模型先生成多个候选 token，再由大模型进行并行验证，以提高大模型推理效率。传统的推测解码通常采用单一路径生成，一旦某个位置验证不通过，后续生成的 token 都会被浪费。

Sequoia 的核心贡献在于把推测生成的过程建模为树结构寻优问题。小模型在生成过程的不同位置存在多种可能的 token 选择（top-1、top-2 等），因此可以构造多种分支路径。Sequoia 利用动态规划算法，为推测生成的 token 寻找最优树结构，以最大化期望接受 token 数。具体来说，给定一定的推测预算（树的大小），算法需要决定如何在每个节点处分支、每个分支延续多长，使得在考虑验证失败概率的前提下，期望获得最高的大模型接受率。此外，该算法还具有硬件感知能力，能够根据具体硬件平台自动选择树的规模和深度。实验结果在 Llama2-7B、Llama2-13B 和 Vicuna-33B 上分别取得最高 、 和  的加速比。这个案例说明本课程学习的动态规划思想不只局限于经典教科书问题，也是分析现代大模型系统性能的一个有力工具。

贪心算法的基本思想与找零问题
贪心算法的基本特征是：每一步选择当前最优的方案，一旦做出选择就不再撤销。与动态规划需要比较多个子问题结果并复用最优子结构不同，贪心算法不做全局比较，只关注眼前步骤。以背包问题为例，如果采用贪心策略，可能每次选择当前价值最大的物品装入（或每次选择重量最轻的物品），但并不考虑这个选择对未来可装入空间的影响。贪心算法的设计通常是容易的，但关键在于判断贪心策略是否能保证全局最优。
