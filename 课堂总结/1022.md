合并果子与哈夫曼合并（P1090）
这是经典的贪心问题，每次从所有果堆中取出重量最小的两堆进行合并，再把合并后的新堆放回集合中。这一策略与哈夫曼编码的构造思想一致。正确性可通过如下方式理解：把合并过程看作一棵二叉树，每一堆初始果子是叶子，其总贡献等于该堆初始大小乘以该叶子在树中的深度。若交换两个最小权值到最深的一对兄弟叶子位置，总代价不会变大，因此反复执行贪心选择可得到最优解。

实现时利用小根堆（优先队列）反复弹出两个最小元素，合并后压回堆中，直到堆中只剩一个元素。时间复杂度 ，空间复杂度 。注意累计答案时可能超出 int 范围，应使用 long long（PPT 代码中 int answer 存在风险）。此外，输出格式要与题目要求一致，每个测试用例输出一行。

不重复数字（P4305）
本题为哈希表模板题。要求对于每组数据，按原顺序保留第一次出现的数字，删除后续重复项。思路是：从左到右扫描输入，用一个 unordered_set<int> 记录已经出现过的数字。当 seen.insert(value) 返回的 .second 为真时，说明该数字首次出现，立即输出（并注意空格分隔）；否则跳过。处理完一个前缀后，集合中恰好包含该前缀内出现过的所有数字，输出即为第一次出现顺序。多组数据的期望时间复杂度为 ，空间复杂度 。若需要保序的映射操作，也可以使用 unordered_map 配合队列等结构，但本题用集合即可。

八数码难题（P1379）
本题是在  棋盘上移动空格（用 0 表示），每次与上下左右相邻的棋子交换，目标是从初始状态变为状态 "123804765"，求最少步数。把每个棋盘状态视为图中的一个节点，一次合法移动视为一条权为1的边，问题转化为求最短路。由于所有边权为1，使用宽度优先搜索（BFS）即可保证首次到达某状态时即得到最短路径，一旦遇到目标状态就可以直接返回步数。

在实现时，把棋盘展开成一个长度为9的字符串作为状态键。使用 queue<pair<string,int>> 进行 BFS，并用 unordered_set<string> 标记已访问状态，避免重复入队。每次搜索状态时，找到空格 '0' 的位置，将其所在行列坐标换算为字符串下标，枚举四个方向并执行边界检查，合法则交换相应字符生成新状态。总复杂度期望为 ，空间 ，其中  为可达状态数。

一个重要的延伸结论是：可达状态数 。为什么不是全部  个排列？如果我们去掉空格（0），剩下 1 到 8 的一个排列。空格在棋盘上左右移动时，这个去掉空格的排列顺序不变，其逆序数奇偶性不变；空格上下移动时，会跨越两个非零数，逆序数变化为偶数，因此奇偶性仍然不变。所以只有逆序数奇偶性相同的两个排列之间才可能相互可达，并且可以证明每一类内部均互相可达。因此所有状态被分成奇偶两类，各占一半。题目保证有解时，无需在代码中显式判断奇偶性，直接 BFS 即可。
