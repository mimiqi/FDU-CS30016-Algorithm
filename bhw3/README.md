**报告入口：[三页PDF报告](作业3.pdf)**；[完整Markdown正文](大作业3_报告正文.md)可编辑。

**进度与接续入口：[当前进度与接续](当前进度与接续.md)。** 2026-10-14已完成20题实验和三页A4报告；235份正式调用记录通过全量完整性审计，PDF已逐页渲染、视觉检查，并核对文字、页数与统计数据。已有数据无需重新采样。

使用用户明确授权的 `gpt-5.6-luna / low`，不使用强化推理；每次新上下文单题作答，不调用工具。Single Run正确率50%，固定5次采样80%，本方法90%、平均6.25次/题。报告如实标注小样本边界，最后思考147字。

## 材料入口

- `作业要求原文.md`：用户提供的要求。
- `实验方案.md`：正式采样前冻结的题型、随机策略、停止与平票规则。
- `题库与标准答案.md`：正式20题和离线标准输出，不能交给被测模型。
- `验证/题库.json`、`验证/冻结清单.json`：题库、提示策略顺序、随机种子和冻结校验值。
- `实验原始记录/Qxx/`：每个独立模型调用的完整输入、JSONL事件、最终原始回答、用量和元数据。
- `验证/experiment.py`：单题独立调用、共享前缀、自适应停止及离线评分。
- `验证/实验结果.json`：从原始回答重新计算的结果，必须检查 `status=complete`。
- `验证/audit.py`：全量完整性检查与控制器回归检查。
- `验证/build_report.py`：从同一组正文和实测数据生成三页PDF、完整Markdown及两张SVG图。
- `验证/报告检查.json`：三页A4、文字与数据检查、逐页视觉验收及PDF校验值。

```powershell

```

已有原始回答不覆盖、不重新采样；失败保留并中止，不能靠重试筛出更好的答案。各方案的每题预算分别计算，比较全体方案的实际采集总量高于每题10次。离线解释器仅制作标准答案和评分，不是求解器的工具。

原始记录通过本目录 `.gitattributes` 禁用Git换行转换，确保上传与跨平台检出后，原始文件的字节校验值仍可核对。
