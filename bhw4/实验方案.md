# Hash 与 LSH 语义检索实验方案

本方案在计算检索结果前确定。目标是在公开文本向量上减少真实余弦计算，并完整呈现召回、候选量、时间和空间的代价，不依据测试集挑选最好看的参数。

## 问题口径

题目原文来自用户于 2026-10-22 粘贴的课程要求，见 `作业要求原文.md`。原文多处公式未随粘贴保留；以下是本实验明确采用的数学定义，不冒充题目原有公式。原文仅写“星期四 23:59”，不推断具体截止日期。

- 历史文本为 x_i，单位向量为 v_i；查询 q 的单位向量为 u。
- Exact Match 为原始字符串完全相等。不转小写、不去标点、不折叠空白。
- Semantic Match 为余弦 u·v_i ≥ τ，预先固定 τ=0.80。
- Ground Truth G(q)={i: u·v_i ≥ τ}，由离线暴力搜索计算。在线 LSH 路径只读取候选向量。
- 余弦是本实验的相关性代理，不能证明历史答案对新请求一定正确。数据集的意图标签不参与检索、参数选择或 Ground Truth 定义。

## 数据和向量

使用 PolyAI BANKING77：官方 train.csv 的 10,003 行作为历史候选来源，按字符串精确去重；实际 N 由程序记录。test.csv 去除与历史完全重复的文本并去重后，用固定种子无放回抽取 300 个查询，不按 Ground Truth 是否非空筛选。另从历史中抽取 100 个完全重复查询，单独评价 Exact 路径。历史顺序固定随机化，规模实验使用其前 2,000、5,000、N 条。

公开模型为 sentence-transformers/all-MiniLM-L6-v2，384 维；使用模型仓库的 ONNX CPU AVX2 无符号 8 位量化导出，attention-mask mean pooling 后 L2 归一化，最多 256 tokens。记录模型 revision、文件 SHA-256、依赖版本和向量 SHA-256。所有方法使用同一份 float32 向量，不训练、不微调，不调用收费 API。

## Exact Hash 和 LSH

Exact 使用 SHA-256(UTF-8 原始字符串) → 文本 ID 列表的哈希表；摘要匹配后再次比较原始字符串，正确处理摘要碰撞。字符串的计算成本为 O(|q|)，哈希表查找期望 O(1)。语义相近字符串没有特殊碰撞待遇。

LSH 独立生成 r~N(0,I_d)，h_r(v)=1[r·v ≥ 0]。单 bit 碰撞概率 p(s)=1−arccos(s)/π；每表 k 位做 AND，L 张表做 OR，进入候选的概率 P(s)=1−(1−p(s)^k)^L。候选按 ID 去重，再按真实余弦阈值过滤，不限额截断，不进行隐式全库回退。

每张表用 uint32 桶偏移数组及 uint32 文本 ID 数组存储；超平面为 float32。查询时只定位 L 个桶，合并其中的 ID。

## 事先推导参数

设计目标为边界相似度 s1=0.80 的单元素进入概率至少 95%，并让低相似度 s≤s0=0.20 的元素进入概率最多 5%。s0 是设计参照，不假定全部无关文本都满足该条件。

对整数 k，从小到大计算 L(k)=ceil(ln(0.05)/ln(1−p(0.80)^k))，取首个满足 P(0.20)≤0.05 的组合。得到 **k=12，L=46**：P(0.80)=0.9520，P(0.20)=0.04665；k=11、L=36 的远点概率约 0.06416，不满足约束。选择最小可行 k，限制表数和超平面计算开销。95% 是对每一对向量和随机索引的理论概率，不是每次查询或所有邻居全部找回的保证。

固定消融：(8,46)、(16,46)、(12,23)、(12,92)，分别隔离 k 和 L 的影响，不据消融结果替换主配置。主配置使用种子 20261022、20261023、20261024，报告随机波动；主表用第一个种子。

## 比较和测量

1. Brute-force：全部 N 次余弦，返回阈值集合。
2. Exact Hash Only：原文命中时返回相等 ID；未命中返回空集。
3. Hash + LSH：Exact 命中直接返回相等 ID；未命中才做 LSH 和余弦过滤。

300 个非完全重复查询是语义 Recall 主表；100 个完全重复查询另表展示精确命中率和零向量计算路径。不能把 Exact 提前返回一个相等答案，误计为找回了所有语义邻居。

- Macro Recall：只在 |G|>0 的查询上平均 |C∩G|/|G|；明确报告空 G 数量，不把空集合记为 100%。另报告 Micro Recall 和至少命中一个相关项的查询比例。
- Candidate Ratio：平均 |C|/N；Exact 未命中为 0。精筛后的输出为 C∩G，因此相对于阈值 Ground Truth 不产生误报。
- Query Cost：记录实际余弦次数 |C|、超平面投影次数 kL、平均与 P95 检索耗时。所有方法使用预计算查询向量，计时包含 Hash、候选生成、去重和精筛；单线程 BLAS、预热后多轮，另列向量编码的成本口径。
- Memory：分别报告公共向量矩阵字节数、Exact 索引 Python 对象递归大小、LSH 持久数组字节数及数组容器开销；原始文本为公共存储单列，模型权重与构建临时峰值不混入索引大小。Exact Only 不需要保留向量。
- 数据规模：固定 k=12、L=46 和同一组超平面，比较 N=2,000、5,000、N，Ground Truth 随历史子集重新定义。

## 规模推导和报告

固定参数时，E|C(q)|=Σ_i P(sim(q,x_i))；如果相似度分布稳定，候选比例可近似稳定而绝对候选量线性增加。对进入概率 α 的无关文本，E false candidates=N_far α。仅增大 k 会损失召回；同步增加 L 会增加空间及投影开销。大规模分析必须同时计入 kLd、候选精筛 d|C|、索引 NL 及桶目录空间，不能声称固定参数在任意 N 下都次线性。
